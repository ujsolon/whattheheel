# Perfect Corp API Pricing and Consumption

## 1. Pricing Plans

| Plan | Cost | Description |
| :--- | :--- | :--- |
| **Free Account** | $0 | Sign up for free units (no credit card needed). |
| **Subscription** | Starts at $24/mo | 500–units/mo., or $0.048/unit, can go up to $460.  Units valid for 60 days. |
| **Pay-as-you-go**| Starts at $27.50 | 500 units, or $0.055/unit, can go up to 10,000 units. Units valid for 1 year. |

*Note: Subscription unit cost decreases with higher volume tiers.*
